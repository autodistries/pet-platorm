"ECONNREFUSED"
→ La base de données n'est pas démarrée
→ Lancez: pnpm run db:start

"Docker n'est pas reconnu"
→ Docker Desktop n'est pas installé
→ Installez-le ou voir ALTERNATIVES_DB.md

"Invalid credentials"
→ Vérifiez email/password
→ Utilisez admin@petshop.com / Admin123!

Tout casser et recommencer
→ pnpm run db:reset
→ Attendre 10 secondes
→ pnpm run dev
